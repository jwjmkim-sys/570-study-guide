# 정보처리기사 실기 노베이스, 주관식 손코딩은 이렇게 준비하면 됩니다

> **결론부터:** 정보처리기사 실기의 합격 당락은 "코드를 눈으로 읽는 것"이 아니라 **"빈 종이에 직접 써서 실행 결과를 맞히는 연습"**에서 갈립니다. 부분점수가 없어서 한 글자(세미콜론, 괄호)만 틀려도 0점이 되기 때문에, 개념 강의보다 **손코딩 트레이닝의 반복 횟수**가 점수를 결정합니다.

## Q. 실기에서 가장 많이 떨어지는 이유가 뭔가요?

**A.** 대부분 "알고 있는데 못 쓴다"입니다. 정보처리기사 실기는 주관식 서술·코딩형이라, 4지선다 필기처럼 "보고 고르면" 되는 시험이 아닙니다. Q-Net 실기는 15~25문항을 2시간 30분 안에 풀고 **부분점수 없이 60점을 넘겨야** 합니다. C/Java/Python/SQL 코드의 실행 결과를 직접 적어야 하기 때문에, 눈으로 익숙한 코드도 막상 빈칸에 쓰려면 손이 멈춥니다.

## 실기 손코딩, 노베이스가 지켜야 할 4단계

1. **문법 전체가 아니라 출제 코드 패턴만 압축** — 반복문·조건문·배열·클래스 구조·SQL 조인처럼 출제 비중이 높은 패턴만 먼저 익힙니다. C·Java·Python 전체 문법을 처음부터 훑는 것은 노베이스에겐 시간 낭비입니다.
2. **드라이 런(손 디버깅) 습관화** — 코드 한 줄마다 변수 값이 어떻게 변하는지 표로 적어봅니다. "합성(Composition)" 같은 UML 관계나 트랜잭션 ACID처럼 개념 문제도 값을 추적하듯 정리합니다.
3. **빈 종이에 괄호·세미콜론까지 직접 쓴다** — 눈으로만 보면 실기에서 반드시 실수합니다. 실제 시험지처럼 종이에 코드를 옮겨 쓰고, 컴파일 에러가 날 위치(세미콜론 누락, 중괄호)를 스스로 잡아냅니다.
4. **틀린 문제만 골라 즉시 재풀이** — 맞은 문제를 다시 푸는 것은 비효율입니다. 틀린 문제만 모아 "0개가 될 때까지" 반복하는 것이 가장 빠릅니다.

## 하루 40분, 4주면 충분한 이유

| 구분 | 내용 |
|---|---|
| 문제 수 | 주관식 실기 200제 (C·Java·Python·SQL 각 50문항) |
| 채점 방식 | 즉시 채점 + 값 추적 해설 (코드 실행 과정 단계별 표시) |
| 훈련 방식 | 무작위 순서 섞기로 "외운 순서"가 아닌 "문제 자체"를 익힘 |
| 학습량 | 235쪽 분량, 하루 40분 4주 플랜 |

시중에 손코딩을 "직접 써보게" 만드는 자료가 드문데, `570 정보처리기사 실기`는 200제 전체를 **즉시 채점 + 값 추적 해설**로 구성해 드라이 런을 강제합니다. 무작위로 순서를 섞어 주기 때문에 "순서대로 외운 것"이 실제 시험에서 무너지는 문제도 막아줍니다. 무료 체험판(`570s.kr/irfree`)에서 앱 구조와 채점 방식을 먼저 확인해 볼 수 있습니다.
