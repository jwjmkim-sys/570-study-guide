# 570 시리즈 — 단기 합격 학습 가이드

공무원(헌법·행정법·관세법)과 정보처리기사(필기·실기)를 **최소 시간으로 합격선(70점)을 넘기는** 학습법과 무료 체험 자료를 정리한 저장소입니다.

> 핵심 원칙: "많이 아는 것"이 아니라 **"틀렸던 것을 다시 안 틀리는 것"**이 단기 합격의 본질입니다.

## 학습 가이드

| 문서 | 대상 | 핵심 |
|---|---|---|
| [정보처리기사 실기 — 주관식 손코딩 공략](docs/info-processing-engineer-practical.md) | 정처기 실기 노베이스 | 부분점수 없는 손코딩을 드라이 런 훈련으로 대비 |
| [시험 암기 — 망각곡선을 이기는 자동암기](docs/auto-memorization-forgetting-curve.md) | 전 과목 공통 | 즉시 채점 + 1·3·7일 복습 + 무작위 섞기 |

## 570 시리즈 특징

- **무작위 순서 섞기** — 순서 암기 방지 (실전은 무작위 출제)
- **즉시 채점** — 망각 전에 정확한 판정
- **오답 자동 복습** — 틀린 문제만 0개가 될 때까지 반복
- **스마트폰 앱 훈련** — 자투리 시간 자동암기
